# Проблема

- Українські Карпати щороку втрачають десятки тисяч гектарів лісу
- Лісництво фізично не може об'їхати кожну ділянку
- Дрони і польові інспекції — повільно й дорого
- А над Карпатами кожні 5 днів літає супутник, який знімає той самий ліс **безкоштовно**

# Ідея

Замість того, щоб людям бігати по горах, нехай супутник дивиться зверху, а програма автоматично знаходить ділянки, де ліс зник.

- Дані: **Sentinel-2** (програма Copernicus, ESA) — безкоштовні
- Метод: порівняти знімок «до» і знімок «після», знайти різницю
- Інтерфейс: веб-сайт з картою, доступний з будь-якого пристрою

# Як це працює: NDVI

`NDVI = (NIR − Red) / (NIR + Red)`

Здоровий ліс відбиває близьке інфрачервоне світло (NIR) і поглинає червоне (Red). Тому в NDVI: ліс ≈ 0.8, ґрунт або вирубка ≈ 0.2.

**Чотири кроки алгоритму:**

1. Беремо два знімки тієї самої ділянки за літо «до» і літо «після»
2. Рахуємо NDVI для кожного пікселя обох знімків
3. Шукаємо пікселі, де NDVI впав більше ніж на 0.2
4. Фільтруємо хмари через шар класифікації сцени SCL від ESA

# Архітектура

```
        Copernicus Data Space (Sentinel-2)
                    │ OAuth
                    ▼
        Python: scripts/generate_data.py
                    │ events.json + PNG
                    ▼
        Next.js + MapLibre GL
                    ▼
        treeguardian.vercel.app
```

Без бекенду, без бази даних, без воркерів. Усе статично — швидко й безкоштовно.

# Технологічний стек

- **Дані:** Sentinel-2 L2A через Copernicus Data Space Ecosystem
- **Аналіз:** Python (`requests`, `numpy`, `Pillow`, `tifffile`)
- **Фронтенд:** Next.js 16 + TypeScript + Tailwind
- **Карта:** MapLibre GL JS + OpenStreetMap
- **Хостинг:** Vercel (Hobby tier)

**Сумарна вартість: 0 грн.** Усе на open-source і безкоштовних тарифах.
